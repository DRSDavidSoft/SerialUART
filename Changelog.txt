v2.4.0
  Separate mini SendCommand and full SerialUART executables. SerialUART opens the
  PortableShell workspace by default; --send, --pipe and --terminal select other modes.
  Replace --tui / --list-json / --list-details with descriptive application/listing
  commands: --interactive, --list-devices and --output-format text|json|ndjson.
  Add dependency-free JSON-RPC 2.0 API over NDJSON stdio IPC, local TCP and WebSocket:
  discovery, explicit port ownership/configuration, binary I/O, events and modem controls.
  Bounded UTF-8 JSON parsing, duplicate-key rejection, per-client cleanup and no replay.
  Add real transport/PTY tests, installed-application checks and both direct builds.
  C ABI remains compatible with v2.x. Physical device acceptance remains separate.

v2.3.0
======
+ Embed PortableShell menus and inline settings in the opt-in --tui serial workspace.
+ Add searchable ports, terminal switching, receive/hex history, send form and modem controls.
+ Add extended native identities, manufacturer/product, location and Windows problem readback.
+ Add --list-json, --list-details, --instance and metadata --match selection.
+ Preserve the v2 C ABI and keep the UI independent of the serial library.
+ Add console model, real PTY session and extended discovery regressions.

v2.2.0
======
+ Port SimplySerial session features into native C host modules.
+ Add raw/display logs, append/overwrite, UTC timestamps and prompt flush/error reporting.
+ Add opt-in profiles, board recognition/custom aliases and include/exclude/block filters.
+ Add NONE/ONE/ANY auto-connect, busy-port fallback and pinned identity checks.
+ Add echo, binary Enter mappings, bounded UTF-8 line editing, bulk input and exit controls.
+ Add streaming OSC title filtering, terminal title/clear controls and expanded Windows keys.
* Correct Windows non-BMP keyboard encoding and retain repeated console key events.
+ Add supported mark/space parity and Windows 5-bit/1.5-stop-bit configuration.
+ Retain SimplySerial board-data MIT notice, offline source snapshot and deterministic importer.
+ Extend session, device-policy, PTY, packaging and direct-compiler validation.

v2.1.0
======
+ Apply the historical serial reference audit; preserve a source-by-source ledger.

+ Add Linux custom baud with termios2 readback/restoration and sysfs-based discovery.
+ Add sendline/until/diagnostic CLI options and a counting-pattern loopback tool.
+ Verify GNU Make and NMake entry points in GitHub Actions.
* Extend PTY, corruption, deadline, native API and installation checks.
