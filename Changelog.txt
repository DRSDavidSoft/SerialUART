Changelog:

v2.1.0
======
+ Apply the historical serial reference audit; preserve a source-by-source ledger.
+ Retain native open errors; read driver configuration, modem status and optional Linux counters.
+ Add bounded TX queue waits, explicit discard and binary delimiter reads with total deadlines.
* Harden POSIX ownership/cleanup and inherited parity/flow-control flags.
+ Add Linux custom baud with termios2 readback/restoration and sysfs-based discovery.
+ Add sendline/until/diagnostic CLI options and a counting-pattern loopback tool.
+ Verify GNU Make and NMake entry points in GitHub Actions.
* Extend PTY, corruption, deadline, native API and installation checks.

v2.0.0
======
- Replace global Windows prototype with a C99 API and opaque independent handles.
- Add Windows/POSIX configuration and byte-counted timed I/O, C++ linkage and shared builds.
- Add OS-native device names and USB filters; reject ambiguous selection.
- Add raw terminal, binary pipes, text/hex commands, DTR policy and serial reconnect.
- Add optional TCP, RFC6455 WebSocket and bounded Socket.IO host adapters.
- Add platform CI, PTY/socket/terminal/official-client tests, sanitizers and packages.
- Add installable CMake targets, source manifests, checksums and attested draft releases.
- Document migration and preserve physical hardware acceptance as separate evidence.
